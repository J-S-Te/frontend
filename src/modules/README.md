# 前端模块与子系统接入边界

当前本地前端模块只有：

| 模块 | 编码 | 来源 |
| --- | --- | --- |
| 基础能力平台 | `basic-platform` | 内置，始终显示 |
| 合同管理 | `contract_management` | 需要后端门户目录返回活动应用后显示 |

`moduleRegistry.js` 是前端代码模块清单，不是平台应用注册表。新增目录或模块定义不会自动创建门户卡片，也不会授予访问权限。

门户卡片规则：

1. 基础平台内置卡片始终存在；
2. 业务卡片只来源于 `GET /api/v1/portal/applications`；
3. 后端返回的名称、说明和公开地址优先；
4. 已集成的合同模块使用 Vue Router；未知独立子系统使用后端 `public_url`；
5. 前端路由守卫只改善体验，后端仍必须鉴权。

新增子系统开发与首次接入见
[子系统开发与统一身份接入手册](../../../platform/docs/subsystem-onboarding.md)。
