# 项目管理前端模块

> 当前基线：2026-07-27。该模块仍为占位目录；接入方式以统一身份认证平台当前的 Cookie 会话、权限、审计、配置和站内信能力为准。风险事件、审计运营和可观测性管理不属于当前平台能力。

## 模块定位

本目录用于存放项目管理系统的前端代码，包括项目立项、计划管理、成员协作、进度跟踪、风险管理及项目归档等业务功能。

## 当前状态

当前仅保留模块目录和说明文件，尚未实现具体业务页面。后续由项目管理开发人员按照基础平台前端规范接入。

## 推荐结构

```text
project_management/
├── api/          # 项目管理后端接口封装
├── components/   # 模块内部复用组件
├── views/        # 路由级业务页面
├── styles/       # 模块专属样式
├── utils/        # 模块工具函数
├── module.js     # 门户展示元数据，不代表已经完成运行时接入
└── README.md
```

## 接入要求

- 复用基础平台提供的身份认证、权限控制、基础审计、配置和站内信能力；运行日志由部署环境统一采集，不依赖平台可观测性管理 API。
- 不在前端保存用户密码、访问令牌或其他敏感凭据。
- 后端接口统一通过模块内 `api/` 目录封装，并携带平台会话 Cookie。
- 新增路由时统一使用 Vue Router 注册，避免在组件中直接判断浏览器路径。
- 模块代码提交后仍须由管理员在“基础能力平台 → 统一登录目标 → 子系统一键接入”完成应用、环境、登录目标和 OAuth 客户端登记；仅存在本目录不会自动显示门户卡片。
- 通用组件优先复用 `src/modules/platform/shared/`，避免重复实现基础能力。
- 业务操作应由后端执行权限校验并记录审计事件，前端权限控制仅用于界面展示。
