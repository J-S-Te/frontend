# 新手导览视觉验收矩阵

适用范围：门户 5 步导览、子系统 3 步导览、上手清单。
自动化基线：`npm run check:vue`、`node --test src/modules/platform/first-run/*.test.mjs`、`first-run-browser.mjs`、`first-run-subsystems-browser.mjs`。

## 1. 视口与主题矩阵

| 场景 | 视口 | 主题 | 检查重点 |
|---|---|---|---|
| 笔记本 | 1366×768 | 浅色 | 气泡不超出视口；首步整行高亮不裁切 |
| 桌面 | 1920×1080 | 浅色/深色 | 气泡上下翻转、左右夹取；深色对比度 |
| 窄屏 | 390×844（≤640px） | 浅色/深色 | 底部面板、`max-height`、滚动、按钮可见 |
| 缩放 | 200%（约 683×384 有效视口） | 浅色 | 文案不截断、按钮不重叠、焦点环可见 |
| 减动效 | 1366×768 | 浅色 | `prefers-reduced-motion` 下无位移动画 |
| 长文案 | 1366×768 | 深色 | 标题/描述换行、气泡不溢出、清单可滚动 |

## 2. 导览浮层检查项

- [ ] 遮罩覆盖视口，不拦截页面键盘焦点；点击遮罩不关闭。
- [ ] 高亮环贴合锚点，内描边，1366/1920 左右不裁切。
- [ ] 气泡默认在锚点下方；空间不足翻到上方；四边不小于 16px。
- [ ] 进度显示“当前 / 总数”，按钮“稍后 / 跳过导览 / 上一步 / 下一步（或完成）”。
- [ ] “稍后”保留步骤并关闭浮层；“跳过导览”才写终态。
- [ ] 焦点进入气泡主按钮；Tab/Shift+Tab 不逃逸；Esc 只跳过当前导览。
- [ ] 关闭后焦点回到原元素；原元素不可用时退到清单入口/子系统导航/主内容。
- [ ] 确认框打开时导览不启动、不抢键盘；层级低于确认框。
- [ ] 深色只使用 token，无十六进制色；`prefers-reduced-motion` 生效。

## 3. 上手清单检查项

- [ ] 标题、进度 n/m、五项任务、探测状态、关闭按钮完整。
- [ ] 无权限任务不展示，分母与文案一致（最多 5 项）。
- [ ] 探测中/未检测到/失败/成功四态文案明确；失败可重试。
- [ ] 面板可滚动；窄屏不遮挡关闭按钮；Esc 关闭并还原焦点。
- [ ] 重置清单只清任务，不影响导览状态。

## 4. 多标签与弹层

- [x] 同一账号两个标签页不同时展示导览（localStorage 租约 + 心跳；P1 已实现）。
- [ ] 切换子系统时旧导览落 paused，不标记完成，不叠加新气泡。
- [x] 非确认框的自定义弹层打开时不启动导览（可见 aria-modal 对话框检测；P1 已实现）。

## 5. 取证要求

每个场景至少截图：导览首步、末步、清单面板、窄屏底部面板、深色。
截图命名：`first-run-<guide>-<viewport>-<theme>-<step>.png`。
验收结论只能是 Pass / Fail / Blocked，并附失败截图与复现步骤。
